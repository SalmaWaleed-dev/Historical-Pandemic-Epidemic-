## 🚀 Project Workflow

### 1. Data Cleaning
To ensure the highest data quality, we implemented a comprehensive cleaning pipeline:
*   **Duplication:** Removed redundant records to maintain data integrity.
*   **Missing Values:** Addressed null entries using statistical imputation (e.g., filling `End_Year` using the mode).
*   **Wrong Format:** Standardized data types for dates and numeric values to ensure consistency.
*   **Outliers:** Identified and managed extreme values to prevent statistical distortion.

### 2. Data Visualization
We leveraged libraries like Matplotlib and Seaborn to create visual representations of the data, uncovering hidden patterns and correlations across different eras and regions.

### 3. Machine Learning Modeling
We developed a predictive framework to analyze and forecast pandemic trends:
*   **Model Selection:** We utilized the **Random Forest** algorithm for its high accuracy and ability to handle non-linear relationships.
*   **Target Objective:** The model aims to predict pandemic severity/impact based on available historical features.
*   **Evaluation:** Performance was assessed using industry-standard metrics to ensure robust results.
